# Todo List

## 입력
- [ ] 참가자 이름을 받을 수 있다.
  - [ ] [예외] 쉼표로 구분한다.
- [ ] 사다리 최대 높이를 입력 받는다.
  - [ ] [예외] 숫자가 아닌 경우
  - [ ] [예외] 1이상의 정수가 아닌 경우
## 출력
- [ ] 참가자 이름들을 출력한다.
- [ ] 사다리의 row는 4칸으로 출력한다.
- [ ] 사다리는 row별로 출력한다.
  - [ ] 이때 col(하나의 높이)을 포함한다. 
## 도메인
#### 참가자
- [x] **이름**을 가진다.
  - [x] [예외] 최대 5글자를 가진다.
  - [x] [예외] 최소 한글자 이상
  - [x] 양쪽으로 빈칸이 없어야 한다.
  - [ ] 이름을 반환할 수 있어야 한다.
  - [ ] 참가자들의 이름은 중복될 수 없다.
- [x] **위치**를 가진다.
  - [ ] 초기값은 [x,0] 이다. -> 결국 위치 책임은 참가자가 아니다!
  - [ ] [예외] 참가자의 x좌표는 참가자 수 미만이다. (0부터 시작)
  - [ ] [예외] 참가자의 y좌표는 최대 높이 미만이다. (0부터 시작)

#### 사다리
- [ ] 사다리는 한 row의 집합체이다 (ex: `|----|----|`)
- [ ] 사다리는 높이를 가진다.
- [ ] 너비를 가진다.
  - 사다리는 높이와 사용자 수로 생성이 된다.
- [ ] `row`
  - `row`는 `point`들의 집합체이다.
- [x] `point`
  - x, y 좌표를 가진다.
  - [x] [예외] 좌표는 음수가 될 수 없다.
